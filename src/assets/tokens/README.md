# Token Assets

This directory contains token logo images used by the TokenAvatar component.

## File naming convention:
- Files should be named using the token symbol in lowercase
- Format: `{symbol}.png`
- Examples: `mon.png`, `usdc.png`, `weth.png`

## Image specifications:
- Format: PNG with transparent background
- Size: 64x64px or higher (square aspect ratio)
- Quality: High resolution for crisp display at all sizes
